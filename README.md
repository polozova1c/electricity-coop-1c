# Учёт электроэнергии для гаражного кооператива

Конфигурация на 1С:Предприятие 8.5 для внутреннего учёта 
потребления электроэнергии в гаражном кооперативе.

Проект внедрён и используется.

## Возможности

- Ведение справочников владельцев и гаражей
- Ввод показаний счётчиков с контролем корректности
- Автоматический расчёт начислений по тарифам
- Учёт оплат и взаиморасчётов

- Отчёты СКД:
  - Задолженность
  - Счётчики к поверке
  - История установок счётчиков и смены собственников по боксам
  - Баланс кВт
  - Расчеты с электросетью остатки
- Печатные формы: квитанция

## Архитектура

### Справочники
- Владельцы
- Гаражные боксы
- Счетчики
- Тарифы
- Вводы электроснабжения

### Документы
- Установка счетчика
- Замена счетчика
- Смена собственника
- Показания счетчиков
- Начисление электроэнергии
- Поступление платежа
- Установка тарифа
- Оплата электросети
- Ввод начальных долгов/переплат

### Регистры сведений
- Цены тарифов
- Собственники боксов
- Счетчики боксов
- Текущие показания
- Счетчики вводов

### Регистры накопления
- Потребление электроэнергии
- Взаиморасчеты
- Расчеты с электросетью
